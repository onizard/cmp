charge mentale partagée

La liste des choses à porter, à deux.

Sur iPhone

  1. Scanne le code — la page s'ouvre dans Safari.
  2. Touche Partager, en bas de l'écran.
  3. Fais défiler, choisis Sur l'écran d'accueil.
  4. Touche Ajouter, en haut à droite.

Sur Android

  1. Scanne le code — la page s'ouvre dans Chrome.
  2. Touche Installer l'application quand la proposition apparaît.
  3. Sinon : menu ⋮ puis Installer l'application.
  4. Confirme par Installer.
